# Respaldo previo a la separación de dependencias

Por solicitud del usuario se preserva el estado existente antes de reorganizarlo
en actual_elements y delete_elements. Se incorporan fuentes, código, modelos,
históricos y entregas/builds locales. Los binarios grandes usan Git LFS.

Las claves y contraseñas de firma, Library, cachés y archivos privados de
compilación quedan fuera de Git; se conservarán localmente. Este commit es un
punto de recuperación del trabajo existente, no una nueva validación móvil.
