# Chupacabras — fuentes Blender

El alcance vigente es una **figura del chupacabras sobre un marcador AprilTag**.
**F1–F6 completadas para una demo AR funcional**. Antes de F7, el usuario
solicita mejorar el personaje y añadir respiración. La [revisión artística](docs/rediseno_nocturno.md)
sustituye únicamente el modelo en la aplicación; la prueba anterior en G20
corresponde al recurso F3, no al nuevo personaje.
